# F12 — Vertical slice terminada

**Objetivo:** **hito de control.** Cerrar la primera misión como una demo pulida antes de construir el resto del juego.

**Requisitos:** Fases 5–11.

**Tareas**

- [ ] **F12.1** Jugar la misión 5 veces seguidas y apuntar todo lo que falle o moleste.
- [ ] **F12.2** Que la jueguen **otras 3 personas** sin ayuda; anotar dónde se pierden o se atascan.
- [ ] **F12.3** Corregir los problemas encontrados.
- [ ] **F12.4** Comprobar rendimiento: **60 FPS estables** en el PC de desarrollo (Profiler de Unity).
- [ ] **F12.5** Hacer una **build de Windows** y probarla fuera del editor.
- [ ] **F12.6** Grabar un vídeo de la misión completa (para seguir la evolución).
- [ ] **F12.7** Etiqueta git `v0.2-vertical-slice`.
- [ ] **F12.8** Revisar el índice de fases y la Biblia: ajustar estimaciones de las fases siguientes con lo aprendido.

**Terminado cuando:** la build se juega de principio a fin sin fallos, a 60 FPS, y quien la prueba entiende qué hacer.
